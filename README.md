# MobileDevRestaurantChooser

To run the app, make sure to install the expo dependencies and run npx expo start

In the app, you will have the decision to add restaurants and people in their respective screens

After adding the people and restaurants, you can go to the decision screen

In the decision screen, select the people who will be joining you

After that, run the restaurant chooser and the app will randomly generate a restaurant for everyone to eat at!
